# nondev-kit

[English](README.md) | **한국어**

AI로 웹사이트나 앱을 만들지만 개발자는 아닌 사람을 위한 Claude Code 플러그인입니다.

**무엇을 만들지는 내가 정합니다. 어떻게 만들지는 Claude가 정하고, 쉬운 말로 설명하고, 중요한 것만 나에게 묻습니다: 돈, 되돌릴 수 없는 일, 개인정보, 제품의 방향.**

> 상태: v0.1, 초기 버전입니다. 안전 검사는 자동 테스트로 확인했습니다. 나머지는 Claude에게 주는 지침이며 아직 실제 사용 경험이 적습니다. [의견](../../issues)을 환영합니다.

쉬운 그림 설명은 [guide.html](guide.html)을 내려받아 브라우저로 열어 보세요.

## 들어 있는 것

| 구성 | 하는 일 | 작동 시점 |
|---|---|---|
| 작업 규칙 | 쉬운 말 설명, Claude가 혼자 정해도 되는 범위, 기본 보안 습관 | 매 세션 자동 |
| 안전 검사 | 위험한 명령 4종류를 실행 전에 막거나 확인을 요구 (아래 참고) | 모든 명령 전 자동 |
| 시작 질문 | "앱 만들어줘"를 고르는 질문 몇 개로 짧은 계획으로 바꿈 | 새 프로젝트이거나 요청이 막연할 때 |
| 오류 질문 | "안 돼요"를 정확한 수정으로 바꿈: 먼저 프로젝트를 직접 확인하고, 무엇을 했고 무엇이 보였는지 물음 | 문제를 자세한 설명 없이 알릴 때 |
| 개발일지 | `DEVLOG.md`: 결정, 꼭 기억할 것, 열린 문제, 작업 기록 | 매 세션 자동으로 읽힘 |
| 보안 점검 | 흔한 실수 12가지를 찾아 쉬운 말로 보고 | 위험한 변경 뒤, 출시 전, 또는 요청 시 |
| 디자인 도구 | 피그마, 캔바 연결 | 디자인 작업이 생길 때 |

## 설치

[Claude Code](https://claude.com/claude-code)와 Node.js 18 이상이 필요합니다.

```
/plugin marketplace add applelog/nondev-kit
/plugin install nondev-kit@nondev-kit
```

설치하지 않고 내려받은 폴더로 바로 써보려면:

```
claude --plugin-dir /path/to/nondev-kit
```

그다음 만들고 싶은 것을 말하면 됩니다.

## 누가 무엇을 정하나

| Claude가 알아서 | 먼저 나에게 묻기 | 내가 직접 |
|---|---|---|
| 도구 선택 | 돈이 드는 일 | 비밀번호 입력 |
| 파일 구조 | 되돌릴 수 없는 일 | 결제 정보 입력 |
| 단순한 오류 수정 | 개인정보 수집 | 약관 동의 |
| | 외부 서비스 가입 | |
| | 제품이 하는 일을 바꾸기 | |

Claude는 내 말에 무조건 동의하지 않도록 지시받습니다. 내가 요청한 것보다 나은 방법이 보이면 근거와 함께 제안하고 답을 기다립니다. 먼저 바꿔 놓고 나중에 알리지 않습니다.

## 안전 검사

작은 스크립트([hooks/guard.mjs](hooks/guard.mjs), 100줄 미만)에 적힌 고정 규칙입니다. 판단에 AI가 관여하지 않습니다.

| 상황 | 동작 |
|---|---|
| 비밀 파일(`.env`, 개인키)이나 알려진 형식의 비밀키가 git에 저장되려 함 | 차단 |
| 공식 npm 등록소에 없는 패키지를 설치하려 함 | 차단 |
| GitHub 저장소를 공개로 만들거나 공개로 바꾸려 함 | 확인 요구 |
| 되돌릴 수 없는 명령: 강제 덮어쓰기, 저장하지 않은 변경 버리기, 프로젝트 밖 폴더 삭제, 실서비스 배포 | 확인 요구 |

검사 자체가 고장 나면 명령을 조용히 통과시키지 않고 확인을 요구합니다.

## 하지 못하는 것

이 부분은 꼭 읽어주세요.

- **앱을 안전하게 만들어 주지 않습니다.** 흔한 실수를 잡아낼 뿐입니다. 보안 점검을 통과했다고 안전이 증명되는 것은 아닙니다. 결제, 건강 정보, 신분증 번호, 어린이 정보를 다룬다면 출시 전에 전문가 점검을 받으세요.
- **Claude가 실행하는 명령만 봅니다.** 내가 터미널에 직접 입력한 명령은 검사하지 않습니다.
- **비밀키 탐지는 흔한 형식만 압니다.** 특이한 형식의 키는 잡지 못합니다.
- **패키지 확인은 npm, pnpm, yarn, bun만 지원합니다.**
- **검사 스크립트는 JavaScript와 TypeScript, 일부 Python만 지원합니다.** 다른 언어는 Claude가 코드를 읽어 검토하며, 이 방식은 신뢰도가 더 낮습니다.
- **안전 검사는 명령의 글자를 읽습니다.** 실수를 막는 용도이지, 일부러 피해 가려는 시도를 막지는 못합니다. 스크립트 파일 안에 숨은 위험한 명령은 보지 못합니다.
- **작업 규칙과 질문 스킬은 코드가 아니라 지침입니다.** Claude는 대부분 따르지만 대화가 아주 길어지면 덜 지켜집니다. 안전 검사만 코드라서 항상 실행됩니다.
- **포토샵은 지원하지 않습니다.** 작성 시점에 공식 연결 방법을 찾지 못했습니다.

## 디자인 도구

플러그인을 설치하면 피그마와 캔바 연결이 함께 등록됩니다. 로그인하기 전에는 아무것도 전송되지 않으며, 디자인 작업에 처음 필요해질 때 Claude가 로그인 방법을 안내합니다. 로그인을 건너뛰면 Claude가 코드로 디자인합니다.

이미 Claude에 피그마나 캔바를 연결해 두었다면 목록에 두 번 보일 수 있습니다. `/mcp`에서 한쪽을 끄면 됩니다.

## 컴퓨터 밖으로 나가는 정보

- 설치하려는 패키지 이름을 `registry.npmjs.org`에서 조회합니다 (설치할 때 어차피 접속하는 곳입니다).
- 보안 점검이 `npm audit`을 실행하며, 이때 사용 중인 라이브러리 목록이 npm 등록소로 전송됩니다.
- 피그마와 캔바는 로그인한 뒤에만 데이터를 받습니다.

그 외에는 없습니다. 사용 기록 수집도 없습니다.

## 더 엄격하게 쓰기

안전 검사는 한 겹의 보호일 뿐입니다. Claude Code에는 자체 권한 규칙과 샌드박스(격리 실행) 기능이 있어서, 패턴 검사가 놓친 경우에도 명령이 건드릴 수 있는 범위를 제한합니다. Claude Code 문서의 권한(permissions)과 샌드박스(sandboxing) 항목을 참고하세요.

## 끄는 법

`/plugin`에서 `nondev-kit`를 끄거나 삭제합니다. `DEVLOG.md` 파일은 그대로 남습니다.

## 테스트

```
node hooks/test.mjs
node skills/security-check/scan.test.mjs
```

모든 규칙에 "잡아야 하는 경우"와 "통과해야 하는 정상 작업"이 있습니다. 패키지 테스트는 인터넷 연결이 필요합니다.

## 기여

버그 제보와 아이디어는 [Issues](../../issues)에 어떤 언어로든 남겨 주세요. 특히 도움이 되는 제보는 이렇습니다.

- 안전한 명령이 막혔거나, 위험한 명령이 통과한 경우 (명령을 함께 적어 주세요)
- Claude가 물었어야 하는데 묻지 않았거나, 너무 많이 물은 순간
- 개발자가 아닌 사람이 이해하기 어려웠던 표현

안전 규칙을 바꾸는 경우에는 `hooks/test.mjs`에 테스트를 추가해 주세요.
